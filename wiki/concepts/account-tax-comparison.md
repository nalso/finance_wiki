# 계좌별 과세 비교

## 요약
화이트보드 필기 기준으로, 계좌 종류별로 원금·수익에 붙는 세율(해외/국내 자산)과 수익을 찾을 때의 건강보험 영향을 정리한 표.

## 상세

필기 표 (손글씨 판독, 일부 미확인):

| 계좌 | 원금(찾을 때) | 수익 해외 | 수익 국내 | 비고 |
|---|---|---|---|---|
| IRP (세액공제) | 0% | 5.5% | 5.5% | 연금계좌 합산 한도 1,500만원 |
| ISA | 0% | 10% | 0% (*표시) | 국내 0%는 *로 강조됨 — 조건은 미확인 |
| (주식) 개인 일반계좌 | 0% | 22% | 0% | 해외 22% = 분리과세 |
| 퇴직연금 | 8~12% | 5.5% | 5.5% | 10년 이상 연금수령 시 30% 감면, 12%→10%로 표기 |
| 개인연금 (세액공제) | 5.5% | 5.5% | 5.5% | |

- 연금(수익) 과세: 세액공제 + 연금수령 시 **3.3~5.5%**. 수령 10년 / 30년 이상 구간에서 4.4%로 표기 (정확한 구간 대응은 미확인).
- 연금계좌 MAX **1,500만원** → **150만원** 환급(세액공제, 10%로 추정) — "전체 150만원에 대해 16.5%"로도 적혀 있음. 16.5%(지방세 포함 공제율로 추정)와의 관계는 **미확인**.
- **건강보험**: 연금계좌에서 수익을 찾을 때 건강보험 부과 여부가 별도 열로 정리됨. 퇴직금 일시불 수령 → 건강보험 **X**(부과 안 됨)로 표기.
- 적립 예시: 30년간 매년 1,500만원 → 30년 후 약 4.5억 (수익률 가정 없음, 원금 기준 합계로 추정).
- 예시: 퇴직연금 IRP 5억을 4%로 운용 → 연 2,000만원 배당·이자.

## 의견 / 해석
- 세율 일부(ISA 해외 10%, 퇴직연금 원금 8~12%)는 필기 해석이 불확실해 법령 확인이 필요하다.
